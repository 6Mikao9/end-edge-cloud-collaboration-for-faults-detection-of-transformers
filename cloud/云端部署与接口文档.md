# 边云协同系统 - 云端部署与接口文档

## 1. 云端服务器部署指南 (47.108.54.154)

### 1.1 需要开放的端口

| 端口 | 协议 | 用途 | 安全组规则 |
|------|------|------|------------|
| 9876 | TCP | 云端服务器主服务 | 允许所有IP访问 |
| 7860 | TCP | Qwen3-VL Swift Deploy | 仅允许内网/白名单IP |
| 9000 | TCP | MinIO对象存储(预留) | 内网访问 |
| 6379 | TCP | Redis缓存(预留) | 内网访问 |
| 3306 | TCP | MySQL数据库(预留) | 内网访问 |
| 22 | TCP | SSH远程管理 | 限制管理员IP |

```bash
# Ubuntu防火墙配置
sudo ufw allow 9876/tcp
sudo ufw allow 7860/tcp
sudo ufw allow 9000/tcp
sudo ufw allow 22/tcp
sudo ufw enable
```

### 1.2 环境安装

```bash
# 1. 登录云端服务器
ssh ubuntu@47.108.54.154

# 2. 安装Python环境
sudo apt update
sudo apt install -y python3-pip python3-venv

# 3. 创建项目目录
mkdir -p /app/cloud-server
cd /app/cloud-server

# 4. 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 5. 安装依赖
pip install -r requirements.txt

# 6. 创建静态文件目录
mkdir -p static

# 7. 启动服务 (使用systemd守护)
sudo nano /etc/systemd/system/cloud-server.service
```

**Systemd服务配置：**
```ini
[Unit]
Description=Cloud Vision Inspection Center
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/app/cloud-server
Environment=PYTHONPATH=/app/cloud-server
Environment=SWIFT_DEPLOY_URL=http://47.108.54.154:7860/v1/chat/completions
ExecStart=/app/cloud-server/venv/bin/python cloud_server.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启用服务
sudo systemctl daemon-reload
sudo systemctl enable cloud-server
sudo systemctl start cloud-server

# 查看日志
sudo journalctl -u cloud-server -f
```

## 2. 边缘服务器配置迁移

### 2.1 配置方式（推荐）

边缘服务器已改为**环境变量配置**，无需修改代码即可迁移：

```bash

export EDGE_ID="EDGE-PROD-001"
export CLOUD_SERVER_HOST="47.108.54.154"
export CLOUD_SERVER_PORT="9876"
export YOLO_MODEL_PATH="/app/models/best.pt"

export ENABLE_AUTO_MODEL_UPDATE="false"

# 启动边缘服务器
python edge_server_cloud.py
```

### 2.2 Docker部署方式（可选）

```dockerfile
# Dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    libgl1-mesa-glx \
    libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖
COPY edge/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY edge/ .

# 环境变量
ENV EDGE_ID="EDGE-DOCKER-001"
ENV CLOUD_SERVER_HOST="47.108.54.154"
ENV CLOUD_SERVER_PORT="9876"
ENV YOLO_MODEL_PATH="/app/models/best.pt"

EXPOSE 8172

CMD ["python", "edge_server_cloud.py"]
```

```bash
# 构建并运行
docker build -t edge-server .
docker run -d \
  -p 8172:8172 \
  -v /local/models:/app/models \
  -e CLOUD_SERVER_HOST="47.108.54.154" \
  edge-server
```

### 3.2 协同训练扩展接口

以下接口为**预留接口**，当前仅返回占位数据，未来实现协同训练时启用。

#### 3.2.1 获取最新模型信息
```http
GET /api/v1/training/model/latest

Response:
{
    "model_version": "yolov10n-v1.0.0",
    "model_url": null,           // 预留: 模型下载URL
    "model_hash": null,          // 预留: SHA256校验
    "release_notes": "初始版本",
    "created_at": 1738291200
}
```

**用途：** 边缘服务器定期轮询，检查是否有新模型版本可用。

#### 3.2.2 下载模型
```http
GET /api/v1/training/model/download/{version}

Response: 模型文件二进制流
```

**用途：** 边缘下载新版本的YOLO模型。

#### 3.2.3 上传难例
```http
POST /api/v1/training/hard-example
Content-Type: application/json

Request Body:
{
    "device_id": "DEV-001",
    "edge_id": "EDGE-001",
    "image_base64": "/9j/4AAQ...",    // Base64编码图像
    "yolo_prediction": {              // YOLO预测结果
        "boxes": [
            {"cls": 0, "conf": 0.45, "xyxy": [100, 100, 200, 200]}
        ]
    },
    "sc_score": 7.5,                  // 场景复杂度分数
    "timestamp": 1738291200,
    "reason": "low_confidence"
}

Response:
{
    "status": "received",
    "example_id": "HE-1738291200",
    "message": "难例已接收，将用于夜间增量训练"
}
```

**用途：** 边缘将YOLO难以处理的样本上报云端，用于增量学习。

**难例定义：**
- YOLO置信度在 0.3-0.6 之间
- SAEC场景复杂度分数 > 阈值
- YOLO检测结果与实际情况不符

#### 3.2.4 获取蒸馏标签
```http
POST /api/v1/training/distill
Content-Type: application/json

Request Body:
{
    "device_id": "DEV-001",
    "edge_id": "EDGE-001",
    "image_base64": "/9j/4AAQ...",
    "temperature": 2.0                // 蒸馏温度，默认2.0
}

Response:
{
    "soft_labels": [0.1, 0.1, 0.6, 0.2],  // 各类别软概率
    "boxes": [                              // 边界框
        {"class": 0, "x1": 100, "y1": 100, "x2": 200, "y2": 200}
    ],
    "feature_map": null,                    // 预留: 特征图
    "teacher_confidence": 0.85              // 教师模型置信度
}
```

**用途：** 边缘获取大模型(Qwen3-VL)的软标签，用于知识蒸馏训练YOLO。

**知识蒸馏说明：**
- 硬标签：one-hot形式 [0,0,1,0]，只有正确类别为1
- 软标签：概率分布 [0.1,0.2,0.5,0.2]，包含类别间相似性信息
- 温度参数T：控制软标签的"软化"程度，T越大分布越平缓

#### 3.2.5 创建训练任务
```http
POST /api/v1/training/task
Content-Type: application/json

Request Body:
{
    "task_id": "TASK-001",
    "task_type": "distillation|incremental|finetune",
    "status": "pending",
    "progress": 0.0,
    "model_version": "yolov10n-v1.1.0",
    "created_at": 1738291200,
    "updated_at": 1738291200
}

Response:
{
    "task_id": "TASK-001",
    "status": "pending",
    "message": "任务已加入队列"
}
```

**任务类型：**
- `distillation`: 知识蒸馏（用大模型软标签训练YOLO）
- `incremental`: 增量学习（用新收集的数据增量更新）
- `finetune`: 全量微调（完整重训练）

#### 3.2.6 查询训练任务
```http
GET /api/v1/training/task/{task_id}

Response:
{
    "task_id": "TASK-001",
    "status": "running",
    "progress": 65.5,
    "logs": ["Epoch 1/10: loss=0.5", "Epoch 2/10: loss=0.3"]
}
```

#### 3.2.7 提交训练反馈
```http
POST /api/v1/training/feedback
Content-Type: multipart/form-data

Form Data:
- edge_id: string
- device_id: string
- model_version: string
- feedback_type: string (false_positive|false_negative|correct)
- image: File
- annotation: string (JSON格式)

Response:
{
    "feedback_id": "FB-1738291200",
    "status": "recorded"
}
```

**用途：** 边缘反馈YOLO预测错误，用于持续改进模型。

#### 3.2.8 获取训练指标
```http
GET /api/v1/training/metrics/{edge_id}

Response:
{
    "edge_id": "EDGE-001",
    "precision": 0.92,
    "recall": 0.88,
    "mAP50": 0.90,
    "inference_time_ms": 15.5,
    "last_updated": 1738291200
}
```

#### 3.2.9 获取训练配置
```http
GET /api/v1/training/config/{edge_id}

Response:
{
    "edge_id": "EDGE-001",
    "learning_rate": 0.001,
    "batch_size": 16,
    "epochs": 10,
    "distillation_alpha": 0.7,  // 蒸馏损失权重
    "temperature": 2.0,
    "update_interval_hours": 24
}
```

**用途：** 云端统一下发训练超参数，边缘按配置执行本地训练。

## 4. 协同训练架构说明

### 4.1 知识蒸馏流程

```
┌─────────────┐      难例图像      ┌──────────────┐
│  边缘YOLO   │ ─────────────────> │  云端Qwen3   │
│  (Student)  │                    │  (Teacher)   │
└─────────────┘                    └──────────────┘
       │                                   │
       │ 硬标签 (0,0,1,0)                  │ 软标签 (0.1,0.2,0.5,0.2)
       │                                   │
       └───────────┬───────────────────────┘
                   ▼
         Distillation Loss = α * L_hard + (1-α) * L_soft
                   ▼
            更新边缘YOLO权重
```

### 4.2 增量学习流程

```
边缘运行 YOLO 检测
       │
       ├── 置信度高 ──> 正常处理
       │
       └── 置信度低 ──> 标记为难例
              │
              ▼
       上报云端收集
              │
              ▼
       夜间批量标注 (Qwen3-VL)
              │
              ▼
       增量训练 YOLO
              │
              ▼
       下发新模型到边缘
```

### 4.3 数据流

```
端侧设备 ──图像──> 边缘服务器 ──难例──> 云端服务器
                      │                  │
                      │ 软标签 <─────────┤
                      │                  │
                      ▼                  ▼
                   本地YOLO          大模型标注
                   增量更新          夜间训练
```
